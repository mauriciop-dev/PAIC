# PAIC - Documentación

**Plataforma de Administración Inteligente de Copropiedades**

Bienvenido a la documentación oficial de PAIC. Aquí encontrarás todo lo necesario para comenzar a usar la plataforma, desde la guía de onboarding hasta el detalle de cada módulo.

## Contenido

- **Introducción** — Qué es PAIC y cómo está compuesta la plataforma
- **Guía de Onboarding** — Recorrido guiado paso a paso
- **Centro de Control** — Dashboard principal
- **Base de Datos** — Gestión de residentes, proveedores e internos
- **Áreas Comunes** — Calendario y reservas
- **Comunicaciones** — Correos masivos y notificaciones
- **Archivos** — Repositorio digital
- **Finanzas** — Ingresos, gastos y resumen financiero
- **Seguridad** — Control de visitantes y paquetes
- **Vencimientos** — Obligaciones y alertas
- **Tareas** — Asignación y seguimiento
- **Configuración** — Perfil, copropiedad, usuarios y suscripción
- **Soporte** — Ayuda y contacto
