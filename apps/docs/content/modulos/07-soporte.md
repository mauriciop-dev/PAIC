# Soporte y Gestión de Sesión

## Botón de Soporte

En la parte superior derecha encontrarás un botón azul siempre visible que despliega una ventana modal con:

- **Videotutoriales:** Acceso inmediato a videotutoriales detallados de cada módulo.
- **Reiniciar Tour Guiado:** Activador manual para reiniciar el recorrido interactivo de onboarding.
- **Contacto de Soporte:** Canales directos de comunicación con el equipo técnico.

## Cierre de Sesión

Haciendo clic sobre tu foto y nombre de usuario en la barra superior, desplegarás el menú para cerrar tu sesión de forma segura.
