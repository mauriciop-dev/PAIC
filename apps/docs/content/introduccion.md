# Introducción a PAIC

Bienvenido a la **Plataforma de Administración Inteligente de Copropiedades (PAIC)**. Una solución integral diseñada para optimizar y automatizar la gestión diaria de administradores de copropiedades, incluyendo:

- Conjuntos residenciales
- Torres de oficinas
- Complejos mixtos
- Complejos de bodegas y centros logísticos

PAIC se divide en **dos componentes principales** para facilitar tu gestión:

## 1. El Chatbot Inteligente

Tu asistente virtual de IA para consultas rápidas. Desde el chatbot puedes:

- Preguntar sobre el estado de cuentas de los copropietarios
- Consultar información general de la copropiedad
- Recibir respuestas inmediatas sin navegar por los módulos

## 2. La Interfaz Modular

El panel operativo donde controlas toda tu copropiedad. Está compuesta por módulos especializados:

| Módulo | Función Principal |
|---|---|
| Centro de Control | Dashboard con resumen general, alertas y notificaciones |
| Base de Datos | Gestión de residentes, proveedores e internos |
| Áreas Comunes | Calendario y reserva de espacios compartidos |
| Comunicaciones | Envío de correos masivos a copropietarios |
| Archivos | Repositorio digital de documentos |
| Finanzas | Control de ingresos, gastos y resumen financiero |
| Seguridad | Registro de visitantes y paquetes |
| Vencimientos | Alertas de obligaciones pendientes |
| Tareas | Asignación y seguimiento de actividades |
| Configuración | Perfil, copropiedad, usuarios y suscripción |
