# Guía de Onboarding Interactiva

PAIC cuenta con un sistema de acompañamiento interactivo por voz y guías visuales en pantalla para ayudarte a dominar la plataforma en minutos. Puedes elegir entre dos modalidades.

## Modo General (Recorrido Corto)

Un tour rápido de interacción mínima diseñado para darte una visión global del sistema en dos grandes etapas.

### 1. El Chatbot

1. **Activación:** El sistema iluminará el botón del chatbot en tu pantalla para que hagas clic en él.
2. **Navegación:** Se resaltará la parte superior del chat donde verás el saludo y las acciones disponibles.
3. **Interacción:** Se iluminará la caja de texto inferior, indicándote que puedes hacer clic en las opciones automáticas o escribir tus dudas libremente.
4. **Cierre:** Para regresar, el tour te guiará para hacer clic en la **X** superior derecha para replegar el chat.

### 2. Recorrido por la Interfaz Modular

A continuación, el asistente de voz te invitará a hacer clic en cada pestaña del menú para activar la explicación interactiva de cada módulo.

## Modo Guiado (Recorrido Completo)

Un recorrido detallado paso a paso por cada módulo y submódulo de la plataforma, explicando sus funcionalidades y cómo usarlas. Este modo es ideal para administradores que quieren conocer a fondo todas las capacidades de PAIC.

## Consejos para el Onboarding

- Asegúrate de tener el audio activado para escuchar las instrucciones de voz
- Sigue las indicaciones visuales (elementos iluminados o con efecto de pulso)
- Puedes saltar el tour en cualquier momento y reiniciarlo desde el botón **Soporte**
