Usuario	tipos de usuario:

Principal: Es la persona responsable del grupo familiar en lo relacionado a la aplicación, también es el usuario que participa en las asambleas y se activa el modulo de Votaciones.

Adicionales: Las personas que conviven con el usuario principal.

Propietario: en caso de que el principal sea un arrendatario y el propietario no viva en el conjunto.

- Activación de usuarios principales:

La persona descarga la aplicación con el enlace o el código QR dispuesto en la administración o en las porterías.

Cuando la persona sea registrada en la pestaña Base de datos el sistema de la administración, entonces se enviara un correo de bienvenida incluyendo el enlace para descargar la PWA de PAIC en el celular	Aparecerá un formulario para incluir hasta a 4 usuarios adicionales. (solo debe incluir el correo de Gmail de cada uno) y el botón enviar

Cada usuario recibe el correo del usuario principal con el enlace para descargar la aplicación con la cuenta de Gmail con la que fue invitado.

Si a alguno de los usuarios adicionales deben restablecer la aplicación, instalarla de nuevo etcetera, este podrá enviar nuevamente el correo de activación.

Siempre recordar la responsabilidad del usuario principal.

Este submódulo de Usuario, no aparece a la WPA de los usuarios adicionales.

Si el usuario principal pierde la app, el teléfono o debe restablecer, debe hacerlo desde la administración o portería según corresponda.
