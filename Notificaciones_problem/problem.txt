❌ El ÚNICO Problema:

❌ type (comunicado, porteria, documento, etc.)
❌ id (del recurso)
❌ tag (para agrupar notificaciones)

Resultado: Cuando hace clic, navega a / genérico en lugar de /comunicados/123 específico.

🎯 Solución en 3 Pasos
PASO 1: Actualizar el Backend

Donde envías las notificaciones, asegúrate que el payload incluya type, id, url:

// ❌ ACTUAL (incorrecto)

  title: "Nuevo Comunicado",
  body: "Revisión presupuestal",
  url: "/"  // ← GENÉRICO

// ✅ CORRECTO (lo que falta)

  title: "Nuevo Comunicado",
  body: "Revisión presupuestal",
  type: "comunicado",        // ← NUEVO
  id: "comm-001",            // ← NUEVO

PASO 2: Actualizar el Service Worker

Reemplaza tu evento push por esto (es prácticamente igual, solo añado tag y mantengo los datos):

javascript
self.addEventListener('push', (event) => {
  const data = event.data ? event.data.json() : { 
    title: 'PAIC Residentes', 
    body: 'Tienes una nueva actualización.',
    type: 'default',
    id: 'default',
    url: '/'
  };

  const payload = {
    title: data.title || 'PAIC Residentes',
    body: data.body || '',
    icon: data.icon || '/logo-paic.png',
    badge: data.badge || '/logo-paic.png',
    tag: data.type || 'default',  // ← NUEVO: agrupa notificaciones por tipo
    data: { 
      url: data.url || '/',
      type: data.type,             // ← NUEVO
      id: data.id                  // ← NUEVO
    }
  };

  event.waitUntil(self.registration.showNotification(payload.title, payload));
});
PASO 3: Mapear tipos → rutas en la app

En tu app (React/Vue), cuando recibe la notificación, navega según el tipo:

javascript
// En tu componente principal o router
self.addEventListener('notificationclick', (event) => {
  event.notification.close();
  const data = event.notification.data;
  
  // Mapear tipo → ruta
  const routeMap = {
    comunicado: `/comunicados/${data.id}`,
    porteria: `/porteria`,
    documento: `/documentos/${data.id}`,
    reglamento: `/reglamentos/${data.id}`,
    default: '/'
  };
  
  const targetUrl = routeMap[data.type] || data.url || '/';
  
  event.waitUntil(
    self.clients.matchAll({ type: 'window', includeUncontrolled: true })
      .then((clients) => {
        const existing = clients.find((client) => client.url.includes(targetUrl));
        if (existing) return existing.focus();
        return self.clients.openWindow(targetUrl);
      })
  );
});
