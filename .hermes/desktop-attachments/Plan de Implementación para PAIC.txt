# Plan de Implementación para PAIC - Basado en Ajustes5.txt

## Resumen Ejecutivo
Este plan detalla la implementación de las cuatro mejoras especificadas en Ajustes5.txt en el orden de prioridad establecido:
1. Sistema de Enlaces Externos a Google Drive
2. Notificaciones Push Nativas del Sistema Operativo
3. Sustitución de Correos Masivos (Resend) por Comunicados en PWA

Cada sección incluye: análisis técnico, pasos de implementación, archivos modificados/creados, dependencias y consideraciones de testing.

## 1. Sistema de Enlaces Externos a Google Drive

### Objetivo
Reemplazar el almacenamiento local de archivos pesados por enlaces públicos de Google Drive en comunicados.

### Análisis Técnico
- **Tabla existente**: `pwa_communications` ya tiene campo `attachment_url` (text) y `attachment_type` (text)
- **Cambios requeridos**: 
  - Frontend: reemplazar input tipo file por input de texto con validación regex
  - Backend: validar que las URLs sean enlaces públicos de Google Drive válidos
  - PWA: mostrar botón de descarga/previsualización para enlaces de Drive

### Pasos de Implementación

#### 1.1 Modificaciones en el Frontend Admin
**Archivo a crear/modificar**: `apps/webapp/components/CommunicationForm.tsx` (o similar)
- Reemplazar `<input type="file" />` por `<input type="text" placeholder="Enlace de Google Drive" />`
- Añadir validación regex en tiempo real:
  ```javascript
  const driveUrlPattern = /^(https:\/\/drive\.google\.com\/file\/d\/[a-zA-Z0-9_-]+\/)|(https:\/\/drive\.google\.com\/folders\/[a-zA-Z0-9_-]+)/;
  ```
- Mostrar mensaje de error si la URL no coincide con el patrón
- Añadir banner informativo permanente:
  > "Asegúrate de que este archivo o carpeta en Google Drive tenga los permisos configurados como 'Cualquier persona con el enlace puede ver' para evitar problemas de acceso con los residentes."

#### 1.2 Modificaciones en el Componente PWA
**Archivo a modificar**: `apps/webapp/components/CommunicationItem.tsx` (o similar)
- Si `attachment_url` existe y es un enlace de Drive válido:
  - Mostrar botón con icono de descarga que abra la URL en nueva pestaña (`target="_blank" rel="noopener noreferrer"`)
  - Si es un archivo individual (contiene `/file/d/`), añadir opción de previsualización mediante iframe:

**Lógica del hook**:
```typescript
const usePushNotifications = () => {
  const [subscription, setSubscription] = useState<PushSubscription | null>(null);
  
  const requestPermission = async () => {
    const permission = await Notification.requestPermission();
    if (permission === 'granted') {
      return await registerServiceWorker();
    }
    return null;
  };

  const registerServiceWorker = async () => {
    if (!('serviceWorker' in navigator)) return null;
    
    const registration = await navigator.serviceWorker.register('/sw.js', {
      scope: '/'
    });
    
    const subscription = await registration.pushManager.subscribe({
      userVisibleOnly: true,
      applicationServerKey: urlBase64ToUint8Array(NEXT_PUBLIC_VAPID_PUBLIC_KEY)
    });
    
    // Guardar en base de datos
    await saveSubscriptionToSupabase(subscription);
    setSubscription(subscription);
    return subscription;
  };

  return { requestPermission, subscription };
};
```

#### 2.5 Implementación del Servidor
**Archivo a crear**: `lib/push-notifications.ts`
```typescript
import webpush from 'web-push';
import { supabase } from './supabaseClient';

// Configurar VAPID (las claves privadas deben venir de variables de entorno)
webpush.setVapidDetails(
  'mailto:tu-email@dominio.com',
  process.env.NEXT_PUBLIC_VAPID_PUBLIC_KEY!,  // Pública
  process.env.VAPID_PRIVATE_KEY!              // Privada (SECRETO)
);

export const sendPushNotification = async (
  conjuntoId: string,
  payload: { title: string; body: string; url?: string }
) => {
  // Obtener todas las suscripciones activas del conjunto
  const { data: subscriptions, error } = await supabase
    .from('push_subscriptions')
    .select('subscription_json')
    .eq('conjunto_id', conjuntoId);

  if (error) throw error;

  // Envío paralelo de notificaciones
  const promises = subscriptions.map((sub) => 
    webpush.sendNotification(
      sub.subscription_json,
      JSON.stringify(payload)
    ).catch(err => {
      // Manejar suscripciones inválidas (HTTP 410/404)
      if (err.statusCode === 410 || err.statusCode === 404) {
        // Eliminar suscripción inválida
        return supabase
          .from('push_subscriptions')
          .delete()
          .eq('subscription_json', sub.subscription_json);
      }
      throw err;
    })
  );

  await Promise.all(promises);
};
```

### Análisis Técnico

### Pasos de Implementación

#### 4.3 Servicios de Procesamiento de Documentos
**Archivos a crear**:
- `lib/drive-connector.ts` - Conecta con Google Drive API

- `lib/embedding-service.ts` - Genera embeddings usando OpenAI o Google

**4.3.1 Conector de Google Drive**
```typescript
import { google } from 'googleapis';

export class DriveConnector {
  private auth;
  
  constructor() {
    this.auth = new google.auth.GoogleAuth({
      keyFile: './credentials.json',  // O usar variables de entorno
      scopes: ['https://www.googleapis.com/auth/drive.readonly']
    });
  }
  
  async listFiles(folderId: string) {
    const drive = google.drive({ version: 'v3', auth: this.auth });
    const res = await drive.files.list({
      q: `'${folderId}' in parents and (mimeType contains 'text/' or mimeType = 'application/pdf' or mimeType contains 'officedocument')`,
      fields: 'files(id, name, mimeType, modifiedTime, webViewLink)'
    });
    return res.data.files;
  }
  
  async downloadFile(fileId: string): Promise<Buffer> {
    const drive = google.drive({ version: 'v3', auth: this.auth });
    const res = await drive.files.get(
      { fileId, alt: 'media' },
      { responseType: 'stream' }
    );
    // Convertir stream a buffer
    return new Promise((resolve, reject) => {
      const chunks: Buffer[] = [];
      res.on('data', (chunk) => chunks.push(Buffer.from(chunk)));
      res.on('end', () => resolve(Buffer.concat(chunks)));
      res.on('error', reject);
    });
  }
}
```

**4.3.2 Procesador de Documentos**
```typescript
import { PDFLoader } from 'langchain/document_loaders/fs/pdf';
import { DocxLoader } from 'langchain/document_loaders/fs/docx';
import { TextLoader } from 'langchain/document_loaders/fs/text';
import { RecursiveCharacterTextSplitter } from 'langchain/text_splitter';

export class DocumentProcessor {
  async extractText(file: Buffer, mimeType: string): Promise<string> {
    switch (mimeType) {
      case 'application/pdf':
        const pdfLoader = new PDFLoader(file);
        const docs = await pdfLoader.load();
        return docs.map(doc => doc.pageContent).join('\n');
        
      case 'application/vnd.openxmlformats-officedocument.wordprocessingml.document':
        const docxLoader = new DocxLoader(file);
        const docs = await docxLoader.load();
        return docs.map(doc => doc.pageContent).join('\n');
        
      case 'text/plain':
        const textLoader = new TextLoader(file);
        const docs = await textLoader.load();
        return docs.map(doc => doc.pageContent).join('\n');
        
      default:
        throw new Error(`Tipo de documento no soportado: ${mimeType}`);
    }
  }
  
  chunkText(text: string): string[] {
    const splitter = new RecursiveCharacterTextSplitter({
      chunkSize: 1000,
      chunkOverlap: 200,
    });
    return splitter.splitText(text);
  }
}
```

**4.3.4 Servicio RAG Principal**
```typescript
import { supabase } from './supabaseClient';

export class RAGService {
  private driveConnector: DriveConnector;
  private documentProcessor: DocumentProcessor;
  private embeddingService: EmbeddingService;
  
  constructor() {
    this.driveConnector = new DriveConnector();
    this.documentProcessor = new DocumentProcessor();
    this.embeddingService = new EmbeddingService();
  }
  
  // 1. Sincronización periódica desde Drive
  async syncDriveFolder(conjuntoId: string, driveFolderId: string) {
    const files = await this.driveConnector.listFiles(driveFolderId);
    
    for (const file of files) {
      try {
        // Descargar archivo
        const fileBuffer = await this.driveConnector.downloadFile(file.id);
        
        // Extraer texto
        const textContent = await this.documentProcessor.extractText(
          fileBuffer, 
          file.mimeType
        );
        
        // Chunking
        const chunks = this.documentProcessor.chunkText(textContent);
        
        // Generar embeddings
        const embeddings = await this.embeddingService.generateEmbeddings(chunks);
        
        // Almacenar en base de datos
        const embeddingRecords = chunks.map((chunk, index) => ({
          conjunto_id: conjuntoId,
          contenido_chunk: chunk,
          embedding: embeddings[index],
          fuente_url: file.webViewLink,
          metadata: JSON.stringify({
            nombre_archivo: file.name,
            tipo: file.mimeType,
            ultima_modificacion: file.modifiedTime
          })
        }));
        
        await supabase
          .from('documentos_embeddings')
          .upsert(embeddingRecords, { onConflict: ['fuente_url', 'contenido_chunk'] });
          
      } catch (error) {
        console.error(`Error procesando archivo ${file.name}:`, error);
        // Continuar con otros archivos
      }
    }
  }
  
  // 2. Búsqueda RAG para consultas
  async query(conjuntoId: string, question: string): Promise<string> {
    // Generar embedding de la pregunta
    const questionEmbedding = await this.embeddingService.generateEmbeddings([question]);
    
    // Buscar fragmentos similares en la base de datos
    const { data: similarChunks, error } = await supabase
      .rpc('match_documents', {
        query_embedding: questionEmbedding[0],
        match_count: 5,  // Top 5 fragmentos más relevantes
        p_conjunto_id: conjuntoId
      });
      
    if (error) throw error;
    
    if (!similarChunks || similarChunks.length === 0) {
      return "No se encontró información relevante en la documentación del conjunto para responder esta pregunta.";
    }
    
    // Construir contexto
    const context = similarChunks
      .map(chunk => chunk.contenido_chunk)
      .join('\n\n---\n\n');
      
    // Aquí se llamaría al LLM (Gemini o GPT-4o) con el prompt enriquecido
    // Para simplificar, retornamos solo el contexto en esta implementación básica
    // En producción, esto se enviaría a un servicio LLM
    
    return `Basándome en la documentación del conjunto, aquí está la información relevante:\n\n${context}`;
  }
}
```

#### 4.4 Función SQL para Búsqueda por Similitud
**Agregar a la migración de embeddings o crear séparada**:
```sql
-- Función para buscar documentos por similitud coseno
CREATE OR REPLACE FUNCTION public.match_documents(
  query_embedding VECTOR(1536),
  match_count INT DEFAULT 5,
  p_conjunto_id TEXT
)
RETURNS TABLE (
  id UUID,
  contenido_chunk TEXT,
  fuente_url TEXT,
  metadata JSONB,
  similarity FLOAT
)
LANGUAGE sql
AS $$
  SELECT
    documentos_embeddings.id,
    documentos_embeddings.contenido_chunk,
    documentos_embeddings.fuente_url,
    documentos_embeddings.metadata,
    1 - (documentos_embeddings.embedding <=> query_embedding) AS similarity
  FROM public.documentos_embeddings
  WHERE documentos_embeddings.conjunto_id = p_conjunto_id
  ORDER BY documentos_embeddings.embedding <=> query_embedding
  LIMIT match_count;
$$;
```

#### 4.5 Interfaz de Consulta para Administradores
**Archivo a crear**: `apps/webapp/components/RAGQuery.tsx`
```typescript
import { useState } from 'react';
import { RAGService } from '../../lib/rag-service';

const RAGQuery: React.FC = () => {
  const [question, setQuestion] = useState('');
  const [answer, setAnswer] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);
  const ragService = new RAGService();
  
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    
    try {
      // Obtener ID del conjunto del perfil del usuario
      const { data: { user } } = await supabase.auth.getUser();
      const { data: profile } = await supabase
        .from('user_profiles')
        .select('conjunto_id')
        .eq('id', user.id)
        .single();
      
      if (!profile?.conjunto_id) {
        setAnswer('Error: No se pudo identificar su conjunto.');
        return;
      }
      
      const result = await ragService.query(profile.conjunto_id, question);
      setAnswer(result);
    } catch (error) {
      setAnswer(`Error al procesar la consulta: ${error.message}`);
    } finally {
      setLoading(false);
    }
  };
  
  return (
    <div className="p-6 bg-white rounded-lg shadow-md">
      <h2 className="text-xl font-bold mb-4">Asistente IA para Documentación del Conjunto</h2>
      <form onSubmit={handleSubmit} className="mb-4">
        <div className="mb-3">
          <label className="block text-sm font-medium mb-2">
            Pregunte sobre reglamentos, actas, contratos o cualquier documento del conjunto:
          </label>
          <textarea
            value={question}
            onChange={(e) => setQuestion(e.target.value)}
            rows={3}
```

## Consideraciones Importantes

### Seguridad
- **Nunca almacenar claves privadas en repositorio**: Usar variables de entorno (GitHub Secrets, Vercel Environment Variables, etc.)
- **Google Drive API**: Los credenciales deben tener el alcance mínimo necesario (`drive.readonly`)
- **VAPID keys**: La clave privada debe mantenerse en secreto absoluto
- **APIs de IA**: Las claves de OpenAI/Google deben almacenarse de forma segura

### Costos Optimizados
1. **Embeddings**: Usar `text-embedding-3-small` de OpenAI (más económico que alternativas)
2. **Almacenamiento**: Los embeddings son relativamente pequeños (~1536 números float32 ≈ 6KB por chunk)
3. **APIs**: Implementar cache de respuestas frecuentes para reducir llamadas a APIs de IA
4. **Google Drive**: Uso de enlaces públicos elimina costos de almacenamiento y transferencia

### Escalabilidad
- Las tablas nuevas (`push_subscriptions`, `documentos_embeddings`) están diseñadas con índices apropiados
- La búsqueda RAG usa índice IVFFlat que escala bien hasta cientos de miles de vectores
- Las políticas de RLS aseguran aislamiento estricto por conjunto

### Prerrequisitos para Implementación
1. **Acceso a Supabase** para habilitar la extensión `pgvector` (fase 4)
2. **Credenciales de Google Cloud API** (ya proporcionadas)
3. **Capacidad para generar y almacenar de forma segura claves VAPID privadas**

```typescript
import { useState, useEffect } from 'react';
import { supabase } from '../services/supabaseClient';

export const usePushNotifications = () => {
  const [subscription, setSubscription] = useState<PushSubscription | null>(null);
  const [isSupported, setIsSupported] = useState(false);

  useEffect(() => {
    setIsSupported('serviceWorker' in navigator && 'PushManager' in window);
  }, []);

  const requestPermission = async () => {
    if (!isSupported) return null;
    
    const permission = await Notification.requestPermission();
    if (permission === 'granted') {
      return await registerServiceWorker();
    }
    return null;
  };

  const registerServiceWorker = async () => {
    const registration = await navigator.serviceWorker.register('/sw.js');
    const sub = await registration.pushManager.subscribe({
      userVisibleOnly: true,
      applicationServerKey: urlBase64ToUint8Array(process.env.NEXT_PUBLIC_VAPID_PUBLIC_KEY!)
    });
    
    await supabase.from('push_subscriptions').upsert({
      user_id: (await supabase.auth.getUser()).data.user?.id,
      conjunto_id: (await supabase.from('user_profiles').select('conjunto_id').eq('id', (await supabase.auth.getUser()).data.user?.id).single()).data.conjunto_id,
      subscription_json: sub
    });
    
    setSubscription(sub);
    return sub;
  };

  return { requestPermission, subscription, isSupported };
};
```

```typescript
import webpush from 'web-push';
import { supabase } from './supabaseClient';

webpush.setVapidDetails(

  process.env.NEXT_PUBLIC_VAPID_PUBLIC_KEY!,
  process.env.VAPID_PRIVATE_KEY!
);

export const sendPushNotification = async (conjuntoId: string, payload: { title: string; body: string; url?: string }) => {
  const { data: subscriptions } = await supabase
    .from('push_subscriptions')
    .select('subscription_json')
    .eq('conjunto_id', conjuntoId);

  await Promise.all(
    subscriptions.map(sub => 
      webpush.sendNotification(sub.subscription_json, JSON.stringify(payload))
        .catch(err => {
          if (err.statusCode === 410 || err.statusCode === 404) {
            return supabase.from('push_subscriptions').delete().eq('subscription_json', sub.subscription_json);
          }
          throw err;
        })
    )
  );
};
```

```sql
CREATE TABLE public.documentos_embeddings (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    conjunto_id TEXT NOT NULL REFERENCES public.conjuntos(id) ON DELETE CASCADE,
    contenido_chunk TEXT NOT NULL,
    embedding VECTOR(1536) NOT NULL,
    fuente_url TEXT NOT NULL,
    metadata JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.documentos_embeddings ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Admins can manage documentos embeddings for their conjunto"
ON public.documentos_embeddings
FOR ALL
USING (
  (SELECT role FROM public.user_profiles WHERE id = auth.uid()) = 'admin'
  AND conjunto_id = (SELECT conjunto_id FROM public.user_profiles WHERE id = auth.uid())
)
WITH CHECK (
  (SELECT role FROM public.user_profiles WHERE id = auth.uid()) = 'admin'
  AND conjunto_id = (SELECT conjunto_id FROM public.user_profiles WHERE id = auth.uid())
);

CREATE INDEX ON public.documentos_embeddings 
USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 100);
CREATE INDEX idx_documentos_embeddings_conjunto_id ON public.documentos_embeddings(conjunto_id);

-- Función de búsqueda por similitud
CREATE OR REPLACE FUNCTION public.match_documents(
  query_embedding VECTOR(1536),
  match_count INT DEFAULT 5,
  p_conjunto_id TEXT
)
RETURNS TABLE (
  id UUID,
  contenido_chunk TEXT,
  fuente_url TEXT,
  metadata JSONB,
  similarity FLOAT
)
LANGUAGE sql
AS $$
  SELECT
    documentos_embeddings.id,
    documentos_embeddings.contenido_chunk,
    documentos_embeddings.fuente_url,
    documentos_embeddings.metadata,
    1 - (documentos_embeddings.embedding <=> query_embedding) AS similarity
  FROM public.documentos_embeddings
  WHERE documentos_embeddings.conjunto_id = p_conjunto_id
  ORDER BY documentos_embeddings.embedding <=> query_embedding
  LIMIT match_count;
$$;
```
